# PaperForge

论文工坊 PaperForge —— 多人协作的论文写作与图表生成项目。

> 仓库创建于 2026-08-18，当前为基础框架，项目说明与分工由团队成员补充。

## 协作方式

- 代码仓库：<https://gitee.com/wujiaohuang/PaperForge>
- 所有改动通过「分支 + Pull Request」合并，具体规则见 [CONTRIBUTING.md](CONTRIBUTING.md)

## 快速开始（成员）

1. 克隆仓库：`git clone https://gitee.com/wujiaohuang/PaperForge.git`
2. 创建自己的分支：`git checkout -b feature/你的功能名`
3. 修改、提交、推送后，在 Gitee 页面上发起 Pull Request
